# Vela

**A modern, fluid and sharp Linux desktop built for today's hardware.**

![The Vela desktop](https://raw.githubusercontent.com/vela-desktop/vela/main/docs/screenshots/start.webp)

Vela is an open-source Linux desktop environment built around a simple idea: modern visuals and efficient software should go hand in hand.

With its own Wayland compositor, Vulkan renderer, and a cohesive suite of desktop applications, Vela is designed to feel responsive, fluid, and precise on modern hardware.

**[Website](https://velade.org) · [Source code](https://github.com/vela-desktop/vela) · [Development journal](https://velade.org/blog/) · [Report an issue](https://github.com/vela-desktop/vela/issues)**

---

## Built with intent

**Modern by design.** A cohesive desktop with refined interactions, polished animations, and native applications.

**Fluid by architecture.** Frame scheduling synchronized to your display, direct scanout, and efficient rendering.

**Sharp at every scale.** Pixel-precise fractional scaling and rendering designed for today's high-density, high-refresh-rate displays.

**Efficient without compromise.** Avoid unnecessary work rather than sacrificing the experience.
